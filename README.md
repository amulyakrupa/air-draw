# 🎨 Air Canvas Ultimate

A gesture-controlled virtual drawing application built using Python, OpenCV, and MediaPipe.

Air Canvas Ultimate allows users to draw in the air using hand gestures captured through a webcam. By tracking the user's index finger in real time, the application converts hand movements into digital brush strokes, creating an interactive and touchless drawing experience.

## ✨ Features

* Real-time hand tracking
* Gesture-based air drawing
* Multiple brush colors
* Rainbow brush mode
* Glow effects
* Particle animations
* Adjustable brush size
* Save drawings as images
* Clear canvas functionality

## 🛠️ Technologies Used

* Python
* OpenCV
* MediaPipe
* NumPy

## 🚀 Installation

```bash
pip install opencv-python mediapipe numpy
```

## ▶️ Run the Project

```bash
python main.py
```

## 🎮 Controls

| Key | Function            |
| --- | ------------------- |
| B   | Blue Brush          |
| G   | Green Brush         |
| R   | Red Brush           |
| Y   | Yellow Brush        |
| P   | Purple Brush        |
| W   | White Brush         |
| N   | Toggle Rainbow Mode |
| +   | Increase Brush Size |
| -   | Decrease Brush Size |
| C   | Clear Canvas        |
| S   | Save Drawing        |
| Q   | Quit Application    |
